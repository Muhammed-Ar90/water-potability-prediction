# 💧 Water Potability Prediction App

A Machine Learning web app built using Streamlit to predict whether water is safe for drinking.

## 🚀 Features
- Water quality prediction
- Confidence score
- SHAP-based model explanation
- Feature importance visualization

## 🧠 Model
- Algorithm: Gradient Boosting
- Features: pH, Hardness, TDS, Chlorine, Sulfate, Conductivity, Organic Carbon, Trihalomethanes, Turbidity

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- SHAP

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run waterpotabilityy.py
